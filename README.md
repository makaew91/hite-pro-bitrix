# СтройМаркет — Интернет-магазин стройматериалов

Интернет-магазин строительных материалов на 1C-Битрикс. Демонстрационный проект, включающий кастомные модули, компоненты, интеграцию с 1С и REST API.

## Стек технологий

- **CMS**: 1C-Битрикс (Управление сайтом)
- **PHP**: 8.1+
- **БД**: MySQL 8.0
- **Кэш**: Битрикс managed cache + композитный кэш

## Архитектура проекта

```
local/
├── modules/makaew.store/       # Кастомный модуль
│   ├── install/                # Установщик модуля
│   ├── lib/                    # D7 ORM-сущности и сервисы
│   │   ├── Api/                # REST API контроллеры
│   │   ├── Calculator/         # Калькулятор расхода
│   │   ├── EventHandler/       # Обработчики событий
│   │   └── Service/            # Сервис-слой
│   └── .settings.php           # Автозагрузка (D7 namespace)
│
├── components/makaew/          # Кастомные компоненты
│   ├── catalog.list/           # Список товаров
│   ├── catalog.detail/         # Карточка товара
│   ├── catalog.section.list/   # Список разделов
│   ├── catalog.smart.filter/   # Умный фильтр
│   ├── sale.basket/            # Корзина
│   ├── sale.order/             # Оформление заказа
│   └── material.calculator/    # Калькулятор расхода
│
├── migrations/                 # Миграции инфоблоков и HL-блоков
├── exchange/                   # Кастомный обмен с 1С
├── agents/                     # Агенты (cron-задачи)
│
└── php_interface/
    ├── init.php                # Точка входа
    ├── events.php              # Регистрация обработчиков
    └── constants.php           # Константы проекта
```

## Ключевые возможности

- **Каталог** с фасетным фильтром и постраничной навигацией
- **Калькулятор расхода** материалов (краска, штукатурка, плитка)
- **Корзина и заказ** с кастомными обработчиками
- **Обмен с 1С** — импорт каталога, экспорт заказов (CommerceML)
- **REST API** для мобильного приложения
- **Highload-блоки** для справочников (бренды, единицы измерения)

## Демонстрируемые навыки

| Область | Реализация |
|---------|------------|
| Кастомные модули | `makaew.store` — полный цикл install/uninstall |
| D7 ORM | DataManager-сущности, сервис-слой |
| Компоненты | CBitrixComponent, кэширование, AJAX |
| Инфоблоки | Миграции, свойства, фасетный индекс |
| Highload-блоки | Справочники с ORM-доступом |
| Sale | Корзина, заказ, обработчики событий |
| REST API | Engine\Controller, middleware, форматирование |
| 1С-интеграция | CommerceML, маппинг цен, логирование |
| Событийная модель | Event handlers, agents |

## Установка

```bash
# 1. Установить Битрикс стандартным способом
# 2. Скопировать local/ в корень сайта
cp -r local/ /path/to/bitrix-site/local/

# 3. Установить зависимости
composer install

# 4. Установить модуль в админке
# Marketplace → Установленные решения → makaew.store → Установить

# 5. Запустить миграции
php local/migrations/migrate.php
```
